# 阶段三 B3：Excel 导入向导与字段来源界面

## 1. 增量结论

本增量完成 Excel 从文件选择、安全预检、诊断筛选、原始单元格核对、逐行冲突修正、warning 明示确认、单事务提交到任务字段来源回看的完整页面闭环。03B1、03B2 的后端门禁与本增量的真实浏览器验收共同覆盖 `AC-XLS-01` 至 `AC-XLS-04`，Excel 工作包提升为 `verified`。

## 2. 完整导入向导

- 仅接受单个 `.xlsx` 文件；浏览器不自行解析业务内容，而是上传到受控预检接口。
- 左侧保留导入历史、状态和创建时间；切换历史记录时清空筛选、warning 确认和提交幂等键。
- 头部展示源文件名、字节数、日期系统、工时换算参数、SHA-256、解析器版本及任务/容器/各级诊断计数。
- 逐行表支持严重度、工作表和建议动作交叉筛选，并显示父子任务、经办人、排期、空工时、Jira 候选、诊断代码与精确单元格坐标。
- 展开行把原值、类型、公式、缓存结果和数字格式分开展示，同时列出规范化结果和 Jira 主字段候选，避免把公式缓存冒充用户原值。
- 修正表单支持创建 Excel 独立任务、选择 Jira 候选逐字段补充或明确跳过；父任务、标题、经办人、日期与工时都作为本次预检修正重新交给服务端校验，不回写源表。
- blocking/conflict 未归零时提交按钮保持禁用；warning 必须勾选明示确认。提交使用稳定的 `Idempotency-Key`，预检版本变化时才轮换键。
- 已提交预检显示创建、链接、补充、保留 Jira 和跳过计数，历史行不能再次编辑。

## 3. 任务字段来源

任务详情新增逐字段 provenance 表，展示字段名、当前来源、合并决定、实际值、决定原因、生效时间和失效时间。界面明确区分 `source_fact`、`supplement` 与 `keep_jira`，并保留已被 Jira 后续事实取代的 Excel 历史，避免只展示最终值而丢失合并依据。

5. 确认提交后页面返回“创建 3、链接 0、补充字段 0、保留 Jira 0、跳过 1”，已提交行不可再修正。
