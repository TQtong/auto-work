# 阶段五 C2：完整季度绩效工作台与导出交互

## 1. 状态与边界

05C2 已把 `/quarterly-reviews` 从功能占位页替换为完整的七阶段季度绩效工作台，贯通已有 05A1、05A2、05B、05C1 的领域能力和 API，状态为 `verified`。阶段 05C 至此已经完成从候选事实到本地 Excel/Word 制品的用户闭环。

工作台坚持本地优先和人工决策边界：AI 不会替用户选入成果、填写用户分或切换当前自评正文；确认和导出不会向公司系统、邮件或钉钉提交材料；外部来源不可用时仍可使用人工成果、规则自评和本地导出。05D 的运维诊断、备份恢复、发布门禁和全量文档终审仍是后续增量。

## 2. 页面结构与状态恢复

页面采用“周期与数据 → 候选池 → 成果编辑 → 指标映射 → 分数 → 自评 → 确认与导出”的完整步骤条。顶部周期选择器、聚合状态、版本、成果总数和导出数量全部来自服务端事实；刷新浏览器后重新读取当前周期、当前步骤、作业和制品，不把关键业务状态只保存在 React 内存中。

季度路由使用独立懒加载 chunk。原有 `FeatureStagePage` 占位组件已经删除，避免任何路由继续展示“稍后接入”的假完成状态。响应式样式覆盖概要区、双列编辑区、评分公式区、模板网格、完整性知悉项和拖放选择区；桌面窄于 1280 像素时切换为单列，不遮挡业务操作。

## 3. 七阶段完整能力

### 3.1 周期与数据

- 创建 Asia/Shanghai 自然季度或自定义周期，显示冻结后的起止日期和版本；
- 选择任务、证据、已确认周报来源，配置新鲜度策略和最大年龄；
- 创建后台收集作业，轮询进度，允许取消，并展示来源快照、状态、数量、警告、错误和完成时间；
- “刷新事实”统一失效季度详情、候选、快照、评分、正文、确认、制品和作业查询，避免局部旧数据冒充最新数据。

### 3.2 候选池

- 支持全部、待处理、已选、已排除、证据不足分组；
- 支持项目、月份、成果来源、证据来源、指标和证据完整性组合筛选；
- 使用游标分页和“继续加载”，筛选变化时清除已隐藏行的批量选择，避免误操作；
- 支持表格多选批量决策、拖入已选区以及聚焦后按 Enter 的键盘替代路径；
- 选入和排除都进入人工原因确认，批量动作只改变选择状态，不自动映射指标、填分或删除被排除成果；
- 行展开区域展示五段成果事实、贡献边界、证据和指标关系。

### 3.3 成果与证据编辑

- 可随时新增人工成果，也可编辑已有成果；
- 表单完整保存背景/目标、个人行动、可验证结果、影响、个人贡献边界和业务期间，编辑时要求变更原因并创建新事实版本；
- 证据编辑区支持标题、外部键、URL、发生时间、可用状态、摘要、贡献角度以及主/辅助证据标记；
- 成果列表独立分页，证据固定展示在成果旁边，不把外部 URL 或摘要发送给未明确触发的 AI。

### 3.4 指标模板与映射

- 可创建并冻结版本化模板，配置稳定代码、名称、定义、权重、最小/最大分、步长、最少证据、必填/启用状态、总分公式和取整规则；
- 模板版本必须显式绑定到评审，旧模板映射不会静默沿用；
- 一项成果可映射多个指标，每条映射必须填写不同贡献角度；
- 覆盖面板同时显示已选成果、成果无证据、成果无指标、必填指标未覆盖和重复证据来源；
- 映射、评分和自评使用不带筛选的独立无限查询自动读取全部成果页，避免只处理前 200 项。

### 3.5 用户评分与 AI 建议

- 评分表同时展示指标定义、范围、步长、权重、独立黄色 AI 建议区、用户分和用户理由；
- 仅健康 AI 连接可触发逐指标建议，连接不可用时按钮明确禁用，人工评分仍可继续；
- AI 建议不会写入用户分，最终计算只读取用户输入；
- 用户分和理由保存后，由服务端重新计算逐项未舍入贡献和最终总分；
- 公式卡展示公式表达式、权重合计、未舍入合计、取整规则、最终分和逐项阻断/通过结果。

### 3.6 自评版本

- 支持基于已选成果生成确定性规则版本；
- 支持人工编辑五段正文并创建不可变新版本，核心成果继续携带成果、指标和证据引用；
- 版本历史可查看来源、版本号、内容哈希、创建时间，并通过“恢复为新版本”保留原版本；
- AI 自评只保存候选，显示净化输入、结果、失败原因和采纳/拒绝决策；只有显式采纳才创建人工派生版本；
- AI 不可用时页面明确降级为规则生成和人工编辑，不伪造 AI 成功。

### 3.7 确认与本地导出

- 确认页展示不可绕过 blocker 和逐项完整性风险；风险必须填写人工核对说明后才允许确认；
- 二次确认明确列出冻结影响，并再次声明“不对外提交”；
- 确认历史展示 active/invalidated 状态、评审基线、时间和快照哈希；
- 仅当前有效确认可以排队生成 XLSX/DOCX；页面轮询 queued/running/终态，运行中制品可取消，失败或取消制品可安全重排；
- 制品表展示格式、状态、结构 QA、尝试次数、文件名、字节数、完成时间、验收事实和下载；
- 验收弹窗公开确认快照、内容哈希、模板版本、结构 QA 报告和渲染事实；下载使用受控 API，不提供上传、邮件或自动提交动作。

## 4. 前端领域模型与测试

Web API 类型补齐季度周期、成果、证据、收集快照、指标模板、评分、自评版本、AI 生成、确认前检、冻结确认和导出制品。下载客户端统一解析 `Content-Disposition` 的 UTF-8 文件名和 ASCII 回退，并在非文件响应时返回结构化 API 错误。

独立视图模型覆盖：

- 服务端聚合状态到七阶段步骤的稳定映射；
- 指标覆盖统计和重复证据来源；
- 用户分范围、步长、理由、权重、未舍入贡献及取整预览；
- blocker/知悉项对确认按钮的门禁；
- 制品成功、结构 QA、下载地址完整性的下载门禁；
- 文件大小和工作流标签的确定性展示。

关键分页续取和批量选择处保留中文代码注释，说明为什么必须清理隐藏选择、为什么映射/评分/自评必须读取全部成果页，避免后续维护者把安全边界误删成简化实现。
