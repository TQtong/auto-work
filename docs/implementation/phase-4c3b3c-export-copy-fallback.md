# 阶段四 C3b3c：六字段复制文本与附件导出人工兜底

## 1. 状态与边界

04C3b3c 已实现日志能力不可用时的六字段预览、“复制为钉钉模板文本”和 UTF-8 文本附件导出，状态为 `verified`。该功能只生成本地人工操作材料：不会创建交付意图、Job、delivery attempt 或机器人通知，不调用钉钉日志/机器人接口，也不操作钉钉网页。

每份材料的首尾都明确标记“未正式提交”，API 固定返回 `submitted=false`。工作台同时展示当前正式日志事实，避免把“生成了兜底材料”和“钉钉已收到正式日志”混为同一状态。

## 2. 当前不可变版本与并发门禁

`POST /api/v1/weekly-reports/:id/export-copy` 要求提交当前 `versionId` 和周报聚合 `reportVersion`。服务端重新读取属于本机用户、未归档的周报，并要求两项都与当前版本完全一致；页面打开后如果其他窗口生成了新版本，接口返回 `VERSION_CONFLICT`，不会悄悄导出旧材料。

工作台存在未保存编辑或正在自动保存时禁用复制/导出入口，并说明导出只读取服务端不可变版本。服务端门禁仍是最终边界，不能由绕过前端的请求跳过。

## 3. 六字段模板文本

服务端从不可变 `weekly_report_version` 逐列读取：填写日期、近期目标、本周内容、下周计划、协助问题和其他补充。字段顺序和名称优先使用该版本冻结的钉钉模板映射；映射缺失、损坏、字段重复或顺序不完整时，不阻断人工兜底，而是使用详细设计裁定的标准六字段名称并返回明确 warning。

外部字段名先做 NFKC 规范化、控制字符清理和长度限制，防止异常模板名称破坏文本分段。空字段不会被伪造成业务内容：结构化响应保留空字符串，复制文本显示“（未填写）”，并在顶部列出空字段 warning。

文本包含：

- “未正式提交”首尾警示和人工核对说明；
- 周报周期、冻结版本号、模板名和本机周报 ID；
- 映射顺序下的六字段名称与完整正文；
- 模板降级或空字段警告。

## 4. 附件字节与完整性

同一次 API 响应返回结构化六字段、可直接复制的 `copyText` 和附件元数据。附件是 `text/plain;charset=utf-8`，文件名含周期、版本号和“未正式提交”，内容使用 CRLF，并在开头添加 UTF-8 BOM，确保 Windows 记事本及常见办公软件直接打开中文时不乱码。

附件返回 Base64 字节、准确大小和 SHA-256。工作台从这些原始字节创建一次性 Blob 下载，触发下载后立即回收对象 URL，避免在浏览器内长期保留额外的完整正文副本。哈希可用于人工核对导出材料是否被修改。

## 5. 审计与数据最小化

每次成功生成材料写入 `weekly_report.export_copy_generated` 审计事件。审计只覆盖 report/version、原版本内容哈希、附件哈希、模板来源、warning 数量和 `submitted=false`；`audit_event` 不保存复制文本、六字段正文或附件 Base64。

复制到系统剪贴板和保存文件都必须由用户在预览弹窗内再次点击。Clipboard API 不可用时，页面使用只存在于当前点击期间的只读临时文本框降级，不写入 localStorage、URL 或诊断日志。

## 6. 自动化证据

- 真实 SQLite 全迁移链集成测试验证冻结模板的六字段名称与顺序、首尾“未正式提交”、完整正文和 `submitted=false`。
- 附件测试验证 UTF-8 BOM、CRLF 正文、Base64 字节、大小和 SHA-256 一致。
- 同一测试前后比较 delivery intent、Job 和 robot notification 数量，证明生成材料没有外部动作副作用。
- 模板缺失测试验证标准六字段降级和空字段 warning；并发版本测试验证旧页面被拒绝且不产生成功审计；所有权测试验证其他身份的周报返回不存在。
- 定向 API 1 个文件/5 个用例通过。
- 全量 `pnpm verify` 通过：Contracts 1 个文件/2 个用例、Domain 8 个文件/31 个用例、API 39 个文件/201 个用例、Web 6 个文件/17 个用例全部通过；格式、lint、类型检查和生产构建同时通过。

本测试没有使用企业钉钉凭证，也没有把导出材料表述为正式日志提交或企业联调成功。

## 7. 后续增量

04C3b3 至此具备预约正式提交、提醒策略与休眠恢复、以及日志能力不可用时的人工复制/附件兜底。下一阶段按详细设计实现季度成果收集、指标映射、评分建议、最终人工评分、冻结快照和 Excel/Word 导出，再完成运维与发布门禁终审。
