# 阶段四 A3b：完整周报工作台与真实浏览器验收

## 1. 本增量边界

本增量把 04A3a 的编辑、恢复、附件、模板/收件人事实和确认内核接入生产 Web，完成可实际操作的六字段周报工作台，并以生产构建、真实 API、全新 SQLite 数据库和真实浏览器走通生成、编辑、历史、确认及确认失效链路。04A3b 状态为 `verified`。

AI 建议/改写仍属于 04B；钉钉真实探测、日志正式提交、机器人通知、失败恢复和部分交付仍属于 04C。因此本增量不会把“已确认”显示成“已提交”，`AC-WRP-03/04` 要在后续能力完成后才能整体标记为 `verified`。

## 2. 完整六字段工作台

- `/weekly-reports` 已从占位页替换为按路由懒加载的正式工作台，支持周报切换、默认工作周生成、自定义周期、严格/允许旧来源策略和未确认候选控制。
- 正文按填写日期、近期目标、本周工作、下周计划、问题与风险、其他事项六字段完整编辑；1.2 秒自动保存和“立即保存”均调用乐观锁编辑接口并创建不可变版本，页面明确显示未修改、待保存、保存中、已保存、冲突和失败状态。
- 确认版本保持只读；用户必须通过二次确认“开始新版本编辑”，首次保存后旧确认追加失效而不删除。
- 工作流步骤严格区分采集、生成、编辑、确认、正式提交和通知。只有外部交付事实成功后才推进正式提交/通知步骤，不根据确认状态伪造成功。

## 3. 历史、比较与恢复

- 历史抽屉展示版本号、来源、时间、变更原因和当前指针，规则、人工、恢复及后续 AI 版本使用一致时间线。
- 字段比较表稳定比较全部六字段并标记变化；不依赖接口返回顺序选择上一个版本。
- 历史恢复、撤销和重做全部调用后端恢复接口，每次生成新的 `restore` 版本。旧版本、父链、来源快照和来源链接始终不被覆盖。
- 撤销会保存撤销前版本到重做栈；新的人工、元数据或历史操作会清空重做分支，避免把不相关事实混入当前编辑路径。

## 4. 模板、接收人、附件与确认预检

- 工作台只列出每个健康钉钉日志连接的当前模板映射版本；模板版本响应显式携带 `connectionId`，接收范围只能从该连接的验证缓存选择。
- 附件入口支持 PDF、DOCX、XLSX、PNG、JPEG、TXT，页面提示 8 MiB 上限。上传成功但版本保存失败时会回收刚创建的附件事实；移除时先保存解除引用的新版本，再标记附件删除。
- 前端确认预检逐项展示六字段、周期/日期、warning、模板、接收范围、附件、计划时间和并发版本；所有非阻断 warning 必须逐项勾选，阻断 warning 不可绕过。
- 只读确认预览显示将锁定的版本、内容哈希、全部正文和门禁结果。最终确认仍由后端在事务内重新校验，前端预检不是信任边界。
- 业务日期不仅校验 `YYYY-MM-DD` 外形，还拒绝 `2026-02-30` 等不存在的公历日期，并拒绝逆序周期或周期外填写日期。

## 5. 真实浏览器验收

验收使用 2026-07-18 的 Web/API 生产构建、临时全新数据库、真实页面交互及已验证钉钉能力快照。浏览器链路结果如下：

| 场景           | 真实结果                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------- |
| 规则生成       | 页面生成当前工作周 v1，展示 warning、来源链接、候选与冻结快照                             |
| 六字段编辑     | 填写缺失字段后自动保存为人工 v2，正文和来源上下文同步刷新                                 |
| 提交元数据     | 选择当前模板映射及已验证接收范围，保存为人工 v3，模板/接收门禁转为就绪                    |
| 历史比较与恢复 | 比较 v2→v3 的全部六字段；从 v2 恢复为新 v4，旧 v2/v3 保留                                 |
| 撤销与重做     | 撤销生成 v5，重做生成 v6，再次撤销生成 v7，版本号连续且父链完整                           |
| warning 与确认 | 只读预览中逐项知悉 warning，锁定 v7 后正文和元数据全部只读                                |
| 确认后编辑     | 二次确认开始编辑，修改其他事项自动保存为 v8；旧确认变为 `invalidated`，周报回到 `editing` |
