# 阶段四 B2a：AI 白名单净化、引用事实校验与生成留痕

本增量完成 04B2 的安全与数据内核：从冻结周报来源重新构造模型白名单输入、秘密/源码/diff 阻断、不可猜测的本地引用、严格结构化输出与引用事实校验，以及不可变 AI 生成记录和人工决定状态约束。它不把“策略函数完成”冒充成可用工作流；建议生成 API、规则回退、AI 建议版本的采纳/拒绝服务和周报工作台入口仍属于 04B2b。

## 数据模型与不可变约束

- 新增 `AiGeneration`，冻结所有会影响一次请求和结果解释的事实：用途、供应商连接及其配置版本、协议/模型、提示词版本、净化策略版本、请求字段、输入引用和类别、移除类别、净化输入哈希、原始输出、解析输出、供应商请求 ID、停止原因、usage、耗时、状态、稳定错误码、安全阻断类别和人工决定。
- 默认 `retentionMode=hash_only`。数据库触发器禁止该模式保存 `sanitized_input_json`；模型凭证本来就没有生成记录字段，源码、diff、环境变量和附件正文也没有可写路径。
- 成功、失败和安全阻断都以结束事件一次写入。成功记录必须具有净化输入哈希、原始输出和合法 JSON 解析输出；失败必须有稳定错误码；安全阻断必须只保存非空类别数组。
- 周报 AI 建议必须是 `origin=ai` 且引用同一周报的一条成功生成记录。生成记录可关联后续人工派生版本，从而满足“AI 原始建议和后续人工版本均保留”。
- 人工决定只允许从 `pending` 单向进入 `adopted` 或 `rejected`。采纳必须指向同一生成记录派生的人工版本，结束后不可反悔；除决定字段外，生成事实不可更新。
- Prisma 为增加外键重建 `weekly_report_version` 时会删除 SQLite 触发器，因此第二条迁移显式恢复周报版本不可变约束，并补回版本号、来源类型、问题栏和 AI 来源一致性校验。

## 只新增白名单的净化器

`sanitizeWeeklyAiInput` 不接收完整数据库对象，也不采用“全部收集后删除”的黑名单做法。它只从以下字段创建一个全新对象：

- 当前选中周报正文栏位；
- 当前用户且可见的 Jira 工单号、项目名、标题、归一状态、计划/截止日期和工时；
- 可用且未拒绝的 Git 元数据标题、证据类型、发生时间和流水线状态；
- 人工输入的正文、栏位和可选项目名；
- 显式同意后的 HTTPS 依据 URL，且始终删除用户名、密码、查询参数和片段。

源码、完整 diff、配置、环境变量、附件内容、Jira 完整描述等额外属性即使被恶意混入调用对象，也不会被读取或序列化。人员姓名、内部 URL 和 Jira 描述摘要分别受独立同意开关控制；未获同意的类别会显示为“已移除类别”，不回显原值。

每个输入块使用 18 字节加密随机数生成 `ref_*` 本地引用。数据库只留引用类型、内部对象 ID、栏位和内容哈希；可读净化正文默认不落库。请求大小使用 UTF-8 字节数保守估算 token，04B2b 会在调用供应商前与连接的 `maxInputTokens` 二次比较。

## 秘密和高敏内容阻断

本地扫描器覆盖并测试以下类别：

- 私钥头；
- Authorization Bearer/Basic；
- OpenAI/GitHub/GitLab/Slack 常见 token 前缀；
- API key、token、secret、password 和 webhook 赋值；
- PostgreSQL/MySQL/MongoDB/Redis 连接串；
- Git diff 头和 hunk；
- Markdown 代码围栏及常见源码声明；
- 客户身份证、银行卡、手机号、邮箱和住址标记。

任一白名单文本命中后整次请求在本地阻断。异常只包含字段路径、策略版本和类别，不包含命中原文，因此后续审计和失败记录也无法泄漏秘密。

## 严格输出与引用事实校验

- 提示词带不可变版本，明确只允许改写输入事实、禁止推断和编造、禁止动作/工具/代码/HTML/diff/凭证，并要求每段至少一个引用。
- 三协议共享动态 JSON Schema：只能返回请求范围内的栏位、段落文本、可空项目名和引用数组，所有对象均 `additionalProperties=false`。
- 本地 Zod 校验再次拒绝额外动作字段、字段缺失/重复、空段落、重复/未知引用、代码围栏和 HTML。
- 每一段出现的 Jira issue key、ISO 日期和数字都必须存在于该段引用直接支持的事实集合；显式项目名也必须由至少一个所引引用支持。引用其他输入块不能绕过逐段事实校验。
- 原始输出有 2 MiB 硬上限，字段文本和段落数量也有独立上限。解析后的正文只是纯文本数据，后续界面不会把供应商 Markdown/HTML 当作可执行内容渲染。

- 持久化集成测试 3 项通过：全新数据库依次执行 12 条迁移，验证 hash-only、非法状态、阻断记录、非当前 AI 建议、人工派生版本、单向采纳、生成/版本不可变、孤儿建议拒绝、外键检查和完整性检查。
- `prisma validate`、API TypeScript 类型检查和本增量测试均通过。
