## 1. 状态与边界

05A1 已完成季度评审周期、完整持久化骨架、版本化指标模板、用户评分和确定性总分计算，状态为 `verified`。本增量没有把尚未实现的候选收集、自评确认和文件导出描述为完成；也没有让 AI 自动选择成果、写入用户分或决定最终总分。

## 2. 周期与评审聚合

- 自然季度 Q1～Q4 固定使用 `Asia/Shanghai`，同时保存闭区间展示日期和下一周期开始日，用 `[periodStart 00:00, nextPeriodStart 00:00)` 处理来源边界。
- 自定义周期验证 NFKC 名称、真实公历日期、有序范围和不超过 367 个自然日。
- 同一用户的周期日期范围和名称分别唯一；创建后名称、周期、时区、自然季度标识、年份和季度均由数据库触发器禁止原地修改。
- 聚合根保存阶段状态、完整性提示、当前指标模板、自评版本、确认和乐观锁版本；修改必须严格递增版本。

API 已增加创建、列表和详情端点，列表只返回当前本机用户的未归档评审并携带成果/导出数量；详情恢复绑定模板、指标和用户/AI 分数的独立事实。

## 4. 版本化指标模板

指标模板保存名称和当前不可变版本。每个版本冻结：

- 明确公式类型：权重百分比平均、权重乘积求和或简单求和；不执行自由文本表达式；
- 取整规则：不取整、四舍五入到整数/一位小数、向下/向上取整；
- 指标代码、名称、定义、权重、最小/最大值、步长、必填、证据要求、顺序和启用状态；
- 规范内容哈希、创建者和时间。

权重百分比公式要求启用项合计精确为 100%，指标代码大小写去重。模板创建使用事务：任何权重、范围或步长错误时模板、版本和指标均为零落库。绑定评审时只接受属于当前用户的已存在模板版本，并为该版本指标建立独立评分行。

## 5. 用户评分与计算明细

- AI 建议分、区间、理由、证据缺口和不确定性使用独立列，绑定模板后默认均为空，不会填入 `userScore`。
- 用户分逐项校验范围、步长和非空理由。即使整张表还没填完，本次单项也不能保存非法分数。
- 部分评分返回 `calculation=null`，但合法单项状态为 `valid` 并保存该公式下的未舍入贡献。
- 所有必填指标完成后，服务端使用未舍入贡献求和，只在模板规定阶段取整，返回分项输入、权重、原始贡献、原始总分、最终总分和中文公式展开。
- 评分或模板变化会使已有确认失效；审计只保存指标 ID、完成状态和计算哈希，不复制评分理由全文。
